# ⏳ Telegram Countdown Bot

Небольшой Telegram-бот на Python, который показывает количество дней до заданной даты и сохраняет статистику использования.

Проект создавался как практическая работа во время изучения Python, Telegram Bot API и Git. По мере разработки бот постепенно получил сохранение статистики, поддержку кнопок и более удобную структуру кода.

---

## 📌 Возможности

- 📅 Показывает количество дней до **2 октября 2026 года**
- ℹ️ Отображает список доступных команд
- 📊 Сохраняет статистику использования
- 💾 Не теряет данные после перезапуска
- 🤖 Поддерживает как команды, так и кнопки Telegram

## 🚀 Запуск проекта

### Клонировать репозиторий

```bash
git clone https://github.com/Andrey22223/countdown-telegram-bot.git
```

### Перейти в папку проекта

```bash
cd countdown-telegram-bot
```

### Создать виртуальное окружение

```bash
python -m venv venv
```

### Активировать его

macOS / Linux

```bash
source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

### Установить зависимости

```bash
pip install -r requirements.txt
```

### Создать файл `config.py`

```python
TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
```

### Запустить бота

```bash
python bot.py
```

## 📊 Что умеет бот

- показывает количество оставшихся дней;
