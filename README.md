# ⏳ Countdown Telegram Bot

Telegram-бот на Python, который считает дни до заданной даты, ведёт статистику использования и общается с пользователем через команды и удобные кнопки.

## 📖 О проекте

Бот показывает, сколько дней осталось до **2 октября 2026 года**, отвечает на команды и клавиатурные кнопки, а также сохраняет статистику обращений между перезапусками в `data.json`.

## ✨ Возможности

- 📅 Показывает количество дней до целевой даты
- ℹ️ Выводит список доступных команд
- 📊 Ведёт статистику использования (сколько раз вызывали каждую команду)
- 💾 Сохраняет данные между перезапусками (JSON-файл)
- ⌨️ Поддерживает как команды (`/start`, `/days`...), так и Reply-кнопки

## 🤖 Команды бота

| Команда  | Описание                              |
| -------- | -------------------------------------- |
| `/start` | Приветствие и краткая инструкция        |
| `/days`  | Сколько дней осталось до целевой даты   |
| `/help`  | Список всех доступных команд            |
| `/stats` | Статистика использования бота           |

Те же действия доступны через кнопки под полем ввода: **📅 Сколько осталось?**, **ℹ️ Помощь**, **📊 Статистика**.

## 🚀 Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/Andrey22223/countdown-telegram-bot.git
cd countdown-telegram-bot
```

### 2. Создайте виртуальное окружение

```bash
python -m venv venv

# Linux / macOS
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Создайте файл конфигурации

Создайте в корне проекта файл `config.py` со своим токеном бота (получить его можно у [@BotFather](https://t.me/BotFather)):

```python
TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
```

> ⚠️ Файл `config.py` не должен попадать в репозиторий — он уже добавлен в `.gitignore`.

### 5. Запустите бота

```bash
python bot.py
```

При успешном запуске в консоли появится сообщение `Бот запущен!`.

## 🔧 Как изменить целевую дату

Дата отсчёта задаётся константой `TARGET_DATE` в файле `bot.py`:

```python
TARGET_DATE = datetime(2026, 10, 2)
```

Измените год, месяц и день на нужные — и бот начнёт считать дни до новой даты.
