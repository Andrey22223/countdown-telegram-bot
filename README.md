# ⏳ Telegram Countdown Bot

Небольшой Telegram-бот на Python, который показывает количество дней до выбранной даты и сохраняет статистику использования.

Проект был создан как первый полноценный pet-проект во время изучения Python. Во время разработки бот постепенно получил поддержку кнопок Telegram, сохранение статистики между перезапусками и более удобную структуру кода.

---

## Возможности
- 📅 Показывает количество дней до **2 октября 2026 года**
- ℹ️ Отображает список доступных команд
- 📊 Ведёт статистику использования
- 💾 Сохраняет данные между перезапусками
- 🤖 Поддерживает команды и кнопки Telegram

## ⚙️ Запуск проекта

```bash
git clone https://github.com/Andrey22223/countdown-telegram-bot.git

cd countdown-telegram-bot

python -m venv venv

source venv/bin/activate

pip install -r requirements.txt

python bot.py
```

Перед запуском необходимо создать файл `config.py`:

```python
TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
```
