# ⏳ Telegram Countdown Bot

Небольшой Telegram-бот, написанный на Python.

Изначально проект создавался как способ попрактиковаться в работе с Telegram Bot API, Git и GitHub. По мере разработки бот постепенно получил дополнительные функции: статистику использования, сохранение данных между перезапусками и удобное управление через кнопки.


## Возможности

- 📅 Показывает, сколько дней осталось до 2 октября 2026 года.
- ℹ️ Выводит список доступных команд.
- 📊 Ведёт статистику использования.
- 💾 Автоматически сохраняет данные между перезапусками.
- 🤖 Поддерживает как команды, так и кнопки Telegram.


## Используемые технологии

- Python 3
- python-telegram-bot
- JSON
- Git
- GitHub

## Установка

Клонировать репозиторий

```bash
git clone https://github.com/Andrey22223/countdown-telegram-bot.git
```

Перейти в папку проекта

```bash
cd countdown-telegram-bot
```

Создать виртуальное окружение

```bash
python -m venv venv
```

Активировать его

macOS / Linux

```bash
source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

Установить зависимости

```bash
pip install -r requirements.txt
```

Создать файл `config.py`

```python
TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
```

Запустить бота

```bash
python bot.py
```


## Что умеет бот

- отображает количество оставшихся дней;
- показывает справку по командам;
- считает количество обращений к каждой функции;
- сохраняет статистику в файл `data.json`;
- автоматически создаёт файл статистики при первом запуске.
