# ⏳ Telegram Countdown Bot

Небольшой Telegram-бот на Python, который показывает количество дней до выбранной даты и ведёт статистику использования.

Этот проект появился как первый полноценный pet-проект во время изучения Python. Главной целью было разобраться с Telegram Bot API, научиться организовывать код, работать с Git и публиковать проекты на GitHub.

---

## Возможности

- 📅 Показывает, сколько дней осталось до **2 октября 2026 года**
- ℹ️ Выводит список доступных команд
- 📊 Ведёт статистику использования
- 💾 Сохраняет данные между перезапусками
- 🤖 Поддерживает как команды, так и кнопки Telegram

## ⚙️ Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Andrey22223/countdown-telegram-bot.git
```

### 2. Перейти в папку проекта

```bash
cd countdown-telegram-bot
```

### 3. Создать виртуальное окружение

```bash
python -m venv venv
```

### 4. Активировать его

macOS / Linux

```bash
source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

### 5. Установить зависимости

```bash
pip install -r requirements.txt
```

### 6. Создать файл `config.py`

```python
TOKEN = "YOUR_TELEGRAM_BOT_TOKEN"
```

### 7. Запустить бота

```bash
python bot.py
```

## 📈 Что умеет бот

После запуска бот способен:

- определять количество оставшихся дней;
- выводить справку по доступным командам;
- считать обращения к каждой функции;
- сохранять статистику после завершения работы;
- автоматически создавать файл статистики при первом запуске.
